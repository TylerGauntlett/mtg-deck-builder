(Scryfall printing `sds/29`). "Starfleet HQ, Under Assault" is a Universes Beyond
alternate name for the same Oracle card, not a separate card:

> Legendary Land — {T}: Add {C}. / {T}, Sacrifice a creature: Add {B}{B}.

The synced list already includes Phyrexian Tower (MH3 printing, `mh3/303`, same
oracle_id `1861e642-21d5-4232-89f3-b5557f2946c1`). Commander is singleton by card
name, and an alternate-name printing counts as the original card, so the deck
cannot run both. There is nothing to add and nothing to cut.
